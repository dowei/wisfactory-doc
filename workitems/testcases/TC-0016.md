2. 注入「有电流且转速>0」数据 → 预期：状态=运行
3. 叠加故障条件命中 → 预期：状态=故障（故障优先于运行）
4. 全部规则不命中 → 预期：UNKNOWN 带质量标记，不显示为任一已知状态
5. 对比设备详情页、车间色块、对外 API 三处 → 预期：同一时刻状态一致；状态变化在 st_item_value 留痕且未变不重写

7. 网关离线事件（LWT/超时） → 预期：无数据超时阈值判离线走判定链（ADR-0004 用例；离线事件链 ADR-0010）
