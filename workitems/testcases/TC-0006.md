1. 执行方式：自动化（命令：待集成测试套件建立后按模块登记；暂手工）
2. 禁用网关后网关上报 → 预期：准入拒绝；重新启用恢复
3. 凭据列表（管理员） → 预期：只返回类型/掩码/key_version/状态，无密文
4. 普通账号访问凭据明文接口 → 预期：403 且操作审计有记录
5. 拉取最新配置快照并校验 SHA-256 → 预期：通过校验且快照体不含凭据密文字段
6. 心跳停止超阈值 → 预期：置离线并产生事件；伪造他网关 ID 拉凭据 → 预期：403（REQ-0009 验收 2、REQ-0011 验收 5）
7. 回写接口越界字段 UPDATE → 预期：被拒（REQ-0009 验收 4）
