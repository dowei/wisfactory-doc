名称：对外调用方管理（appKey 开通、scope 授权与密钥轮换）
所属模块：管理系统（Java）
目标角色：租户管理员（开通与授权）；数据中台对接负责人
优先级：P0
业务目标：数据中台及外部系统调用数据服务 API 的身份与授权管理——一个调用方一行，开通、授权范围、限流、密钥轮换与吊销全生命周期受控；密钥只存哈希（与框架对敏感字段的处理思路一致）。
业务能力：调用方 CRUD 与开通（iot_api_client：app_key 全局唯一随请求传递；secret 哈希加盐存储，创建时明文只展示一次；client_name、备注）；scope 授权（JSON 实例 id/编码数组含子树标记；scope 为空表示无任何数据权限、不是全部——默认拒绝）；限流配置（每分钟最大请求数，0 不限、仍受平台总限流约束）；密钥轮换（到期前支持双密钥新旧并行一周）与吊销（status 置禁用立即生效——验签前先查状态、走缓存且变更主动失效）；到期时间管理；调用方管理页（开通、scope、轮换密钥，详细设计 T12 任务组成）；调用审计 iot_api_call_log 由数据服务写入（REQ-0027 侧）。
核心规则：secret_hash 不明文落库，验签时以原文密钥在服务端重算签名比对；app_key 创建后不可改；调用方只能访问本租户数据（tenant_id 归属）；禁用立即生效；本 REQ 为 REQ-0027 对外查询 API 与 REQ-0028 推送订阅的鉴权前置。
非目标：不做 OAuth2（TD-0004 缺省签名方式，接口层预留鉴权策略接口）；不做调用方自助注册；不做计费。
验收标准：1. 开通调用方时明文 secret 仅展示一次，库中只查到哈希；2. scope 为空的调用方调用任何数据接口返回 403 或空（默认拒绝）；3. 轮换期间新旧双密钥均可验签，并行一周后旧密钥失效；4. 吊销后立即 403 且缓存主动失效（无 TTL 空窗）；5. 管理页可完成开通/scope/轮换/吊销全操作并留操作日志；6. 列表与详情永不返回明文密钥。
原始来源：用途：数据中台及其他外部系统调用数据服务 API 的身份与授权。一个调用方一行，授权范围以模型实例范围（scope）限定，限流与有效期独立配置。密钥只存哈希，创建时明文只展示一次。／调用方管理页（开通、scope、轮换密钥）
来源：工厂数据采集系统详细设计（数据库与接口） §1.10、§3.5、§5（T12）
