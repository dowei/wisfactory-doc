名称：高危配置操作权限收紧与操作审计
所属模块：管理系统（Java）
目标角色：租户管理员（分配配置权限）；普通查看角色默认无配置权
优先级：P1
业务目标：防误改——改公式、改绑定、改部门绑定关系属高危操作，除数据范围外还要单独的操作权限与审计，普通查看角色默认无配置权；改错一条公式→全厂指标错。
业务能力：高危配置操作清单单独注册操作权限（改公式、改绑定、改部门绑定、改状态规则、改阈值、发布/回滚、凭据 edit/view〔ADR-0006 双权限先例同模式〕、手动重算）；权限标识按总约定 iot:资源:动作 录入 sys_menu（menu_type=3）；每类变更产生操作日志（操作人、时间、前后值）；普通查看角色按钮不可见且直调配置 API 返回 403。
核心规则：操作日志与业务时间线分工不重复双写——框架 sys_operate_log 记「谁调了接口」，iot_data_item_history（REQ-0018）记「业务值前后变化」；班次日历一期不建（字段预留），其权限点不建。
非目标：不做配置变更审批工作流（文档未要求）；不做权限矩阵报表。
验收标准：1. 普通查看角色登录：改公式/改绑定/改部门绑定/改状态规则的按钮不可见，直调对应配置 API 返回 403；2. 上述每类变更产生操作日志（操作人/时间），业务值前后变化记入业务时间线（分工见核心规则，不双写）；3. 权限标识全部按 iot:资源:动作 注册且与接口清单一一对应。
原始来源：配置权限另行收紧——改公式、改绑定、改班次日历、改部门绑定关系属于高危操作，除数据范围外还要单独的操作权限与审计，普通查看角色默认无配置权。
