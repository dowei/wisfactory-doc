名称：数据服务对外查询 API（/openapi/v1）
所属模块：数据服务（Java）
目标角色：数据中台及外部系统（持 appKey 调用）
优先级：P0
业务目标：一期边界「向数据中台提供数据服务」的查询通道——中台按唯一键查实时值、历史序列、指标结果、资产树，与平台同一套编码同一口径。
业务能力：六个查询接口（models/tree〔scope 内实例及子树〕、items/realtime〔批量≤200 个 fullKey，优先 Redis 返回 v/q/ts〕、items/history〔原始粒度跨度≤7 天超限必须带 interval 降采样，agg=SUM/AVG/MAX/MIN〕、metrics/query〔返回 value 与 yoy/mom，上期无数据或分母 0 返回 null 并带 compareNote 不返回 0 冒充〕、points/history〔只查不算，跨度≤31 天〕、dict/sync〔appKey 有效即可，模型与数据项字典增量同步〕）；鉴权 appKey+HMAC-SHA256 签名（请求头 appKey/timestamp/nonce/sign，防重放窗口 5 分钟）+scope 裁剪（验签后先以 scope 裁剪再走与内部相同的子树展开）；数据权限经 REQ-0002 同一组件；调用审计 iot_api_call_log（一切错误含 403 统一记录，403 类全量，保留期 180 天按月归档）。
核心规则：【TD-0004 未决】对外鉴权签名 vs OAuth2——详细设计缺省 A（一期签名落地、接口层预留鉴权策略接口，中台若强制要求 OAuth2 可替换策略不改业务接口），需人类点头。【TD-0031 未决】一期是否 6 接口全量交付还是允许裁剪（缺省建议全量：dict/sync 是中台对齐编码的必要件）。实时值优先读缓存未命中回源 TDengine 最新一条并回填。
非目标：不做 OAuth2（除非 TD-0004 改判）；不做匿名查询；不做中台侧自定义聚合；不下发控制指令。
验收标准：1. appKey+签名调用 models/tree 仅返回 scope 授权子树；scope 外详情类请求 403 且全量记录、数据不存在类返回空集；2. 限值契约生效：realtime>200 拒绝、history 跨度>7 天未带 interval 拒绝、points/history 跨度>31 天拒绝；签名错 6001、限流 6002、范围外 6003；3. 每次调用（含 403）在 iot_api_call_log 可查 appKey/接口/结果码/耗时；4. metrics/query 上期无数据返回 null+compareNote 而非 0。
原始来源：REST API 查询：中台按唯一键查实时值、历史序列、指标结果；带鉴权、分页与时间范围限制，并受 10B 节数据权限约束。／对外鉴权 appKey + 签名：请求头带 appKey、timestamp、nonce、sign（HMAC-SHA256……防重放窗口 5 分钟）。
