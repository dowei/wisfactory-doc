# 分期遗留清单（phase2-backlog）

二期 / 三期启动时，本清单必须作为 intake 的固定输入——先核对本清单再开新需求，避免一期搁置项被遗忘。新增 REQ 的非目标中每写一条「二期/三期」，必须同步登记进本清单（CONV-04）；一期收口验收（REQ-0032）含清单核对项，核对未完成一期不得收口。

条目格式：编号、内容、来源坐标、触发条件、一期留下的接口缝。本清单是工作记录，不进索引。

## 二期

- **PB-01** 班次统计模块（班次模板、班次日历实例、可插拔窗口生成器的班次实现、班次筛选与班组对比展示）。来源：TD-0002 → ADR-0012；产品设计 §7A。触发：任一工厂提出班次统计需求。接口缝：REQ-0026 已预留 calendar_type 字段与窗口生成独立接口，二期只加窗口生成器 + 2-3 张表 + 展示筛选，不动已上线指标。
- **PB-02** 接入调试完整版（通道原始报文实时预览）。来源：TD-0018 → ADR-0012。触发：现场联调反馈需要实时报文预览（一期死信/异常队列明细不够用）。接口缝：REQ-0013 已产出死信计数/异常队列数据；约束——与「统一消息模型只存原始报文摘要」契约冲突，需评估旁路短存管道 + 契约版本升级。
- **PB-03** 正式压测门槛（多大规模算达标）。来源：TD-0033 → ADR-0012。触发：试点上线容量复算完成后、接入第二家工厂或生产扩容前。一期只做试点容量复算（试点活动，非二期功能）。
- **PB-04** Modbus / OPC UA / PLC 协议适配器（按现场需要逐个实现，每个约 1-1.5 人月）。来源：REQ-0012 非目标、产品设计 §13；一期已用模拟 Modbus 骨架验证扩展路径（REQ-0012 验收 1）。触发：新工厂现场清单出现对应协议。接口缝：一期已预留 OPC UA 发现字段（ADR-0013 增补 3，待上游修订⑥），自动发现不改表结构。
- **PB-05** 补算与重算工具完善（全量历史刷数、重算任务优先级调度）。来源：REQ-0021 非目标、产品设计 §13。触发：公式改版批量刷历史或大范围修正需求出现。接口缝：REQ-0021 内部 recalculate 接口一期已实现（能力一期、界面二期）。
- **PB-06** 运营方授权看数工作流（租户发起授权、时效、审计查询页）。来源：TD-0042 → ADR-0011；一期为硬隔离 + 审计埋点。触发：云端多租户运营需要合规看数流程。
- **PB-07** 租户级展示配置（总览上卡叠加配置、涨跌颜色语义可配）。来源：TD-0039 → ADR-0011。触发：租户反馈展示偏好需求。接口缝：一期「上看板」标记已随模板/指标定义落地。
- **PB-08** 实例属性表与负载率落点（额定功率等属性参数、负载率类指标）。来源：TD-0012 → ADR-0011 附提醒。触发：**试点指标清单确认后立即评估**——若负载率高频需要，实例属性表提前到一期收尾/二期开局。
- **PB-09** 平台预置模板维护 + 跨租户复制接口。来源：REQ-0004 非目标、TD-0009（复制遇字典缺码：报错清单+先导字典）。触发：第二个租户开通前。接口缝：iot_model_template.tenant_id 可空字段一期已建。
- **PB-10** 中台反向同步（建点事件回传）与数据项级推送完善。来源：TD-0032 → ADR-0010、产品设计 §13「三通道完善」。触发：中台绑定自动化需求出现。接口缝：一期 dict/sync 出站同步已交付。
- **PB-11** 模拟量死区启用评估。来源：TD-0038 → ADR-0010；字段已建（iot_point.deadband）。触发：**试点容量实测后**——实际入库量超预期才考虑，启用需重新评估「无变化未写入」与「缺失」的完整度语义。
- **PB-12** JUMP 突变检测启用。来源：TD-0017 → ADR-0010；码位 8 已预留（CONV-02）。触发：试点真实数据标定跳变阈值后开启，避免设备启停正常跳变刷假异常。
- **PB-13** 计算状态库独立实例平迁。来源：详细设计 Q1 缺省 A（ADR-0009）。触发：计算量级上来后。接口缝：表结构不变、独立账号已隔离，可平迁。

## 三期

- **PB-14** 告警闭环（阈值、离线、突变的规则配置→处理→关闭）。来源：产品设计 §13、REQ-0031 非目标。接口缝：一期阈值字段（ADR-0007）、站内通知通道与系统事件告警记录表（ADR-0013 增补 6——一期已含系统事件类的记录/列表/确认闭环，三期做的是业务阈值事件化与通知矩阵/升级策略）已预留。
- **PB-15** 报表（能耗日报/月报自动生成与导出）。来源：产品设计 §13。
- **PB-16** 能效分析扩展（单位产品能耗、峰谷电分析）。来源：产品设计 §13；口径需另行定义。
