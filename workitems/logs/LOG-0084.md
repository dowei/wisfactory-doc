**问题分析**：用户界面测试反馈"最上级实例怎么绑定数据项"。核查确认后端 `PUT /iot/item/bind`（TASK-0036）已具备，但前端 item-api.ts 零 bind 方法、实例数据项抽屉无绑定按钮——用户在界面上无法完成"数据项绑定具体点位"。同时用户指出模板只是基础、每个实例必须能自定义（后端 bindPoint/saveFormula/saveRollup/overrideParams 四接口齐全，前端只接了阈值），这条 bind 入口是实例自定义的第一块。

**实现方案**：纯前端微改——item-api.ts 加 bindPoint + point-api.ts 加 queryList；新建点位选择弹窗 item-point-bind-modal.vue（a-modal+a-table 单选启用点位 status=1，选中调 bindPoint→成功提示+刷新，**defineExpose({showModal})** 吸取 BUG-0008 教训）；instance-item-drawer.vue 每行加「绑定点位」按钮（iot:item:edit）+「绑定点位」列（pointCode 优先/pointId 映射/失败退化显示）。

**实现内容**：提交 4de39ec7（主体 bb013a9c + hygiene 4de39ec7，8 文件全 frontend：2 api + 1 新弹窗 + drawer + 3 测试 + 既存 spec 补 mock），零 backend 改动。
