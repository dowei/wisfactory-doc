背景：竞品借鉴清单（开源工业 IoT 同类产品 12 项调研，ThingsBoard / JetLinks / Neuron / eKuiper 等）A 类增补共 6 项 + 2 可选小项，总增量约 +3~5 人月（一期原估 20~28 人月）。分两类：契约/地基型须赶在统一消息模型冻结（ADR-0009 TD-0046 前置门）之前；能力型纳入一期、排尾部增量可顺延 1.1 期。
候选方案：A 全部采纳；B 仅采纳契约/地基型、能力型全部二期；C 逐项评估。
决定：A——全部采纳，落点与修正说明如下：
1. 增补 1（网关断网缓存语义成文，+0.5~1 人月）：落点修正为 REQ-0013（接入处理与幂等）+ **REQ-0014（边缘网关自治——缓存语义的主体在 0014，原清单写的 REQ-0009 是网关台账管理，不是缓存语义承载对象）**。内容：缓存落盘方式；容量上限与满后淘汰策略（**取舍未定 → 新增 TD-0051**，what 级不能自定）；补传触发与确认机制（平台 ACK 后才删本地缓存）；补传限速参数；幂等键 (pointCode, ts)+batchId 确认纳入统一消息模型冻结契约（时点：TD-0046 冻结门之前）。
2. 增补 2（协议适配器隔离与注册心跳契约）：落点 REQ-0012 + 详细设计接入层。每个适配器独立部署单元；启动注册、周期心跳；单适配器崩溃不影响其他适配器与接入主链路；适配器版本与配置契约按多适配器形态定版（一期仅 MQTT/HTTP 两个实例）。
3. 增补 3（点位表预留 OPC UA 发现字段，增量 0）：落点 REQ-0008 + 详细设计 iot_point（预留节点标识/浏览路径可空字段）；二期 OPC UA 节点浏览自动发现（phase2-backlog PB-04）不改表结构。
4. 增补 4（数据权限拦截抽象为策略接口，增量 0）：落点 REQ-0002 + 详细设计数据权限拦截。一期实现不变（部门范围→可见实例集），拦截点按策略接口实现，预留单数据项粒度扩展位，避免二期重构查询层。
5. 增补 5（公式试算窗口曲线，+1~1.5 人月）：落点修正说明——REQ-0016/0020 与详细设计 §3.1/§3.4 **已有单点试算（validate/preview/trial）**，本增补是增强而非新建：选定公式+时间窗，用历史点位数据沙箱试算输出**结果曲线预览**（不落库），与配置发布影响预览配套（预览看影响面、试算看算得对不对）。新增独立开发任务行；排期：计算引擎稳定后、试点批量配置公式之前就位。
6. 增补 6（系统事件告警最小闭环，+1.5~2.5 人月）：落点修正说明——REQ-0031 已有「站内异常通知」，本增补是升级为**告警记录生命周期管理**（生成、列表、确认/处理状态、一种站内通知出口），并入 REQ-0031 同域交付、不另立 REQ。范围严格限定：仅系统事件（设备/网关离线、数据超时未达、网关缓存积压）；不含业务阈值告警事件化、通知矩阵、升级策略（三期不变，阈值一期仍只驱动展示标红）。新增告警记录表与管理接口 → 新任务行。
7. 可选小项：A2 点位 Excel 批量导入——**REQ-0008 已承接**（批量导入导出为业务能力+验收标准 2），无需动作；A7 对外 API 补 IP 白名单——采纳，REQ-0027 增加 appKey 级可选 IP 白名单配置（与签名、scope、限流、审计叠加，增量约 0）。
理由：第一类四项是契约/地基型——缓存语义与幂等键不进冻结契约、适配器契约不按多适配器形态定版、OPC UA 字段不预留、权限不抽象策略接口，二期都要返工（改表、改契约、重构查询层），推迟成本远高于现在；第二类两项是能力型增量，尾部排期可顺延不返工；增量合计 +3~5 人月在一期 20~28 人月盘子内可消化。A2 已在 REQ-0008 承接不重复。
影响范围与副作用：REQ-0002/0008/0012/0013/0014/0016/0020/0027/0031 正文增补（关联决策补本 ADR）；新增 TD-0051（网关缓存满后淘汰策略，what 级）；待上游修订清单由 5 项增至 10 项（⑥ iot_point 预留 OPC UA 发现字段；⑦ 网关断网缓存语义成文——落盘方式/容量上限/ACK 后删缓存/补传限速，淘汰策略随 TD-0051；⑧ 适配器注册心跳契约成文；⑨ 计算试算接口补时间窗曲线输出并新增任务行；⑩ 新增告警记录表与管理接口并新增任务行；⑪ 对外 API appKey 级 IP 白名单）；phase2-backlog PB-04 补字段预留备注、PB-14 补一期边界说明；一期开发增量 +3~5 人月，第二类两项排尾部、工期紧可顺延 1.1 期；统一消息模型冻结清单增加「幂等键字段」确认项（TD-0046 门内）。
关联对象：REQ-0002、REQ-0008、REQ-0012、REQ-0013、REQ-0014、REQ-0016、REQ-0020、REQ-0027、REQ-0031；phase2-backlog PB-04、PB-14。
