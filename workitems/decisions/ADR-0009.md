背景：spec-intake 呈报契约产出 50 条 TD（todo.md）；人类于 2026-11-21 会话对第一批 13 条逐条裁决。本 ADR 留痕定版结论（明细已同步写进各 REQ 正文），裁决后的 TD 从 todo.md 删除。
候选方案：各条均有「维持缺省 / 改判 / 搁置」三向；本批全部落定，无搁置项。
决定：逐条定版如下——
1. TD-0003（Q1）：业务库与计算状态库同实例分 schema + 独立账号，量级上来后可平迁独立实例（表结构不变）。落点：REQ-0022、REQ-0023。
2. TD-0004（Q2）：对外鉴权一期 appKey+HMAC-SHA256 签名，接口层预留鉴权策略接口，中台若强制 OAuth2 可替换策略不改业务接口。落点：REQ-0027。
3. TD-0005（Q3）：状态量按 INT 枚举存储，展示与对外接口返回时翻译为文本。落点：REQ-0007、REQ-0008、REQ-0013。
4. TD-0013：状态编码独立稳定字典（只增不删、禁用不复用序号），历史 st_item_value 序号不漂移。落点：REQ-0007。
5. TD-0014：一期补「点位枚举值→状态编码」直绑映射配置（挂模板、随发布下发），直绑状态与规则判定共用展示链，直绑优先。落点：REQ-0007。
6. TD-0015：未绑定点位锚点——子表标签 instance_key 留空、归属以绑定关系为准；权限按「所属位置」部门拦截、无位置仅租户管理员可见。落点：REQ-0008。
7. TD-0016：补传/迟到消息豁免时间纠偏，纠偏仅对超出补传窗口的异常时间戳生效并打标记。落点：REQ-0013。
8. TD-0021：质量码数值枚举扩至 0-9——0 正常、1 超上限、2 超下限、3 断线/超时补标、4 设备异常值、5 手工补录、6 计算失败、7 汇总不完整、8 突变待核查、9 跨周期用量；产品文本码映射 GOOD→0、OVER_RANGE→1/2、STALE/OFFLINE→3、JUMP→8、MANUAL→5；CALC_ERR 不落时序行（归计算日志）。枚举表落 CONV-02，随统一消息模型契约冻结。落点：REQ-0016、REQ-0017、REQ-0019。
9. TD-0025：指标层重算记录复用 iot_calc_log（full_key 承载指标全键），不新增独立日志表。落点：REQ-0022、REQ-0025。
10. TD-0026：完整度按「应到周期值的到达率」计——非 GOOD 质量码的值计入缺失、停用时段剔除。落点：REQ-0025。
11. TD-0027：指标来源允许上游指标级联（定义增加来源类型标记），月年指标可由日结果逐级聚合，重算传播沿依赖图。落点：REQ-0024、REQ-0025。
12. TD-0046：统一消息模型、配置快照 Schema、TDengine 超级表结构三份契约冻结后第一批接入方可进入联调（冻结为联调前置门）；契约变更必须升版本并通知各系统。落点：CONV-03。
13. TD-0048：人工补录/修正改走管理面接口（质量码 5、记操作审计），ingest 通道收敛为纯机器上报，统一消息模型不增加来源字段。落点：REQ-0013、REQ-0021。
理由：TD-0003/0004/0005 维持详细设计 §6.2 缺省（运维简单 / 对接快且留策略接口 / 存储查询高效且与 INT 列一致）；其余各条按缺省建议成立，理由已随定版文字写进对应 REQ 正文。三件事打包成一件事获人类整体赞成：质量码 0-9、补录走管理面、契约冻结前置门——口径一致性好、契约冻结一次到位。
影响范围与副作用：REQ-0007、REQ-0016、REQ-0017、REQ-0022、REQ-0023、REQ-0027 解除阻塞（可进批量确认）；REQ-0008、REQ-0013 各自仅剩 TD-0038 / TD-0017 未决；质量码枚举 0-9 写入 CONV-02 并进统一消息模型冻结契约；契约冻结前置门写入 CONV-03（T8 联调前置）；详细设计 DDL 注释「是否同实例见正文待确认 Q1」可按本 ADR 更新；仍未决 TD 余 35 条（48-13）。
