任务描述：现状数据项唯一写入源是模板生成，实例只能 bind/formula/rollup/params 改已有项，无法手动新增或删除数据项，导致「模板只作初始基线、实例可增删」不成立（ADR-0017 ④）。本任务新增实例级数据项新增/删除接口。**风险核对三行**：①改动范围=仅后端 dataitem controller/service/mapper + 权限登记 sql + 测试；②引用 grep=现有 delete 语义仅 regenerate 软删引用，需新增独立 DELETE；③语义影响=软删（@TableLogic）、编码唯一（uk 不含 deleted，删除后编码占用）、被引用数据项删除保护、locked 仅改状态、数据权限 fail-closed。
技术方案和要点：①新增 `POST /iot/instance/{instanceId}/item`（body: dataCode/dataName/sourceType/...，按 IotDataItem 现有字段白名单）与 `DELETE /iot/item/{itemId}`（或批量 ids）；②权限码 iot:item:add / iot:item:remove 已核实登记于 `resources/sql/upgrade/20261122_iot_data_item_domain.sql`，无需新增登记；③软删+被引用（iot_data_item_ref 或指标引用）拒绝删除；④数据权限：目标实例必须 ∈ 可见集否则 403；locked 实例拒绝结构变更（仅状态可改）；⑤新增后 full_key=instance_code.data_code，租户内唯一双道闸。
