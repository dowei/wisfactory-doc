任务描述：BUG-0007 修复——`AlarmTimeoutScanner`（@Component）构造器 `int timeoutSeconds` 漏 @Value，Spring 启动报 required a bean of type 'int'，后端 8098 起不来。**风险核对三行**：①改动范围=AlarmTimeoutScanner.java 构造器 1 参数 + 1 个装配测试文件；②引用 grep 结论=同类 InspectResultStore/NoticeOutboxNotifier 无 @Component 经 @Bean 注入（有 @Value），不受影响，全仓仅此一处 @Component 裸 int；③语义影响=仅补配置注入，timeoutSeconds 默认值 300 不变，定时扫描行为不变。
技术方案和要点：构造器第三参数改 `@Value("${ot.alarm.data-timeout-scan-seconds:300}") int timeoutSeconds`；加 Spring 上下文装配测试（@SpringBootTest 太重时用 ApplicationContextRunner 只装该类 + mock 依赖，断言 bean 可创建），确保启动类缺陷被单测覆盖（旧版必红/修后绿）。
