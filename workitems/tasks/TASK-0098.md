技术方案和要点：
1. 数据层软下线（根仓库 resources/sql/，本业务自有、不碰框架只读子树）：新增 resources/sql/upgrade/20261125_disable_survey.sql（新脚本，不改 02_survey.sql 历史初始化脚本）——
   - UPDATE sys_module SET status = 0 WHERE code = 'survey' AND deleted = 0;（模块切换器不再显示"问卷调查"）
   - UPDATE sys_menu SET visible = 0 WHERE module_id = 3 AND deleted = 0;（侧栏隐藏问卷菜单，router 的 hideInMenu: visible === 0 生效）

2. 去掉前端入口（让用户在界面上看不到、也进不去）：

   - **保留** survey 的 views/api/components/store/assets/composables/plugin/types/utils 代码文件本身，不做物理删除——避免与上游分叉，且后端服务仍需要这些 API 类型定义不冲突。
