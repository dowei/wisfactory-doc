任务描述：需求要求工厂/车间/产线等组织节点套模板后生成初始数据项、模板变更纳入待升级链。**核实结论（计划评审核实后）**：生成链 `IotDataItemServiceImpl.generateForInstance` 的短路是 `if (templateId == null) return 0`——按**有无模板**判定，不是按 nodeType；待升级链 `IotInstanceUpgradeServiceImpl.selectUpgradeList` 按 templateId+版本判定，也不按 nodeType。前端实例表单对 node_type 1/2/3 模板下拉已支持（非必填）。因此组织节点新建时选模板即自动按模板生成数据项、自动纳入待升级链，**现有能力已覆盖，无需改生产代码**。本任务降为验证性任务：补契约测试固化该既有行为（组织节点套模板生成、待升级纳入、重生成只增不改不删），不改业务逻辑。**风险核对三行**：①改动范围=仅后端测试文件（新增/扩展 1-2 个测试类），不改生产代码；②引用 grep=generateForInstance 被实例创建同事务与 regenerateForInstance 两处调用，本任务不改动其逻辑只验证；③语义影响=无（纯测试固化既有行为，不改权限/编号/展示规则）。
技术方案和要点：①读代码确认三处既有行为（生成按 templateId、待升级按 templateId+版本、组织节点模板下拉），写成契约测试：新建 node_type=1/2/3 且带 templateId 的实例 → 生成数据项 full_key=组织编码.数据编码；新建无模板组织节点 → 零生成不报错；②测试待升级清单 selectUpgradeList 对组织节点实例（引用模板且版本滞后）返回该行；③测试重生成「只增不改不删」——先改造一项（改公式）再重生成，改造项不被覆盖、模板删项保留；④若测试发现既有行为与上述不符（真缺口），停下报告并按实现缺陷另建 BUG，不在本任务偷改生产代码。
