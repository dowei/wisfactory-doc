名称：网关、通道与凭据管理

触点：后台
关联任务：TASK-0017；TASK-0018；TASK-0019；TASK-0020
关联用例：TC-0006
优先级：P0
功能定义：边缘网关台账与准入控制、采集通道配置（MQTT/HTTP+类型预留）、通道凭据密文生命周期管理——网关编码即设备身份，凭据全链路不落明文。
页面与操作：网关管理页（CRUD/在线状态/启停）；通道配置页（按网关查列表/连接配置 JSON）；凭据管理（列表掩码/写入轮换/查看明文/吊销）。
功能项与字段：gateway_code 64 字符租户内唯一；channel_code 网关内唯一；protocol_type 字典四值（MODBUS/OPCUA 可建不可启用）；conn_config JSON Schema 约束不含凭据；credential（cred_type、SM4 密文 {v1}、key_version）。
业务规则：gateway_code/channel_code 不可改；回写字段组固定（online_status/last_heartbeat_time/ip_addr/version/config_version）；凭据 edit/view 双权限+审计、列表只回掩码；凭据不进快照与 config.changed；变更经配置发布生效。
异常与边界：空数据=通道未配凭据接入失败明确报错；越权=edit/view 分权、网关令牌只拉本网关凭据；并发=同通道凭据并发编辑后者生效+审计；超限=凭据明文永不回显。
实现方式：SM4 复用框架 {v1} 约定；密钥环境变量/密钥服务；网关凭令牌 HTTPS 单独拉取内存解密。
关联决策：ADR-0006、ADR-0011
