名称：配置发布中心

实现需求：REQ-0033
触点：后台
关联任务：TASK-0024；TASK-0025；TASK-0026
关联用例：TC-0008
优先级：P0
功能定义：保存≠生效的版本化发布机制——按 scope 生成快照（SHA-256+对象存储）、下发记录 ACK 三态、超时重发、回滚、config.changed 通知。
页面与操作：发布页（scope 选择/发布说明必填/影响预览）；版本列表页（哈希/发布人/时间）；下发状态页（各目标 ACK 状态/失败原因/重发）。
功能项与字段：scope_type（1 网关 2 计算）、version 单调递增、snapshot_hash、snapshot_uri、publish_status；publish_log（target_type 网关/接入/计算、ack_status 三态、error_msg）。
业务规则：并发发布报 5001、未确认 5002；生效以发布为准（TD-0034 定版）；快照不含凭据（ADR-0006）；通知只作触发信号；回滚=以旧快照生成新版本；模板第二档变更发布强制影响预览+二次确认（ADR-0008）。
异常与边界：空数据=无变更发布提示；越权=发布高危权限；并发=5001 版本冲突；超限=万级点位快照分片/压缩（次要）。
实现方式：快照 JSON Schema 版本化；对象存储走框架 sys_file/MinIO；ACK 超时扫描用定时任务。
关联决策：ADR-0005、ADR-0006、ADR-0008
