+      // 成功后行消失（已对齐不出现）；失败（4002 已在目标版本/并发冲突）提示刷新清单——两态都重查
+      await ajaxQuery();
+    }
+  }
+
+  // ---------------- 锁定开关（行操作列；锁定实例不自动跟随二档变更） -----------------
+
+  function confirmToggleLock(row: TemplateUpgradeRow) {
+    const locking = row.locked !== 1;
+    Modal.confirm({
+      title: locking ? '锁定确认' : '解除锁定确认',
+      content: locking
+        ? `确定锁定实例【${row.instanceCode ?? '-'} ${
+            row.instanceName ?? ''
+          }】吗？锁定后该实例不自动跟随二档变更（语义变更），保留在待升级清单逐台确认后再升级。`
+        : `确定解除实例【${row.instanceCode ?? '-'} ${row.instanceName ?? ''}】的锁定吗？解除后回归跟随面（二档变更随发布自动生效）。`,
+      okText: locking ? '锁定' : '解锁',
+      onOk() {
+        doToggleLock(row, locking);
+      },
+      cancelText: '取消',
+      onCancel() {},
+    });
+  }
+
+  async function doToggleLock(row: TemplateUpgradeRow, locking: boolean) {
+    try {
+      OtLoading.show();
+      await upgradeApi.setInstanceLock({ instanceId: row.instanceId, locked: locking ? 1 : 0 });
+      message.success(locking ? '已锁定：该实例不再自动跟随二档变更' : '已解除锁定：该实例回归跟随面');
+    } catch (e) {
+      otSentry.captureError(handleIotConflictError(e));
+    } finally {
+      OtLoading.hide();
+      // 锁定徽标即时反映（清单行不因锁定变化而消失，但重查保持行数据新鲜）
+      await ajaxQuery();
+    }
+  }
+
+  onMounted(() => {
+    loadTemplateOptions().then(() => {
+      // 模板页入口携 ?templateId= 预选并自动查询
+      const templateIdParam = Number(route.query.templateId);
+      if (templateIdParam > 0 && templateOptions.value.some((opt) => opt.value === templateIdParam)) {
+        queryForm.templateId = templateIdParam;
+        ajaxQuery();
+      }
+    });
+  });
