+# calc — 计算引擎（Java · Spring Boot 4）
+
+工厂数据采集系统的计算引擎：按租户拉取计算范围配置快照（scopeType=2，scopeId=0，租户
+粒度），重建依赖图；新图构建成功才原子切换，构建失败保持旧图运行并回执失败——配置错误
+不许打停正在跑的计算（详细设计 V1.1 §3.3 p25）。工程骨架初始化于 2026-11-23
+（TASK-0040 开线；目录规划裁决：根仓库新增 `calc/` 独立顶层 Maven 工程，与
+`backend/`、`frontend/`、`ingest/` 平级——go/ingest 同款平级先例，独立 mvn 不与
+backend 道撞车）。
+
+## 目录
+
+```

+## 消费语义（§3.3 p25 逐条对齐）
+
+- **快照拉取**：`GET /internal/v1/config/snapshot?scopeType=2&scopeId=0[&tenant=]`——
+  信封 Result\<InternalSnapshotVO\>（version/snapshotHash/snapshotUri/schemaVersion/
+  snapshot）。**哈希可重算校验**（BUG-0005 修复后出站体=原始字节透传）：对
+  data.snapshot 原文重算 SHA-256 == snapshotHash，不一致 fail-closed 拒绝应用；
+  信封与快照体 version 同值校验（§3.3）；RawJsonExtractor 逐字节保真提取
+  （任何树再序列化都会改写数字形态——BUG-0005 病灶）。
+- **依赖图构建**：节点=数据项/指标全键（点位以编码为键）；边=引用（公式→上游数据项，
+  iot_data_item_ref 行；点位直绑 refType=2 → 点位输入节点）、汇总→子级（同 dataCode +
+  实例路径子级——fullKey=instanceCode+"."+dataCode 结构派生，快照不含模型域对象见契约
+  差异第 11 条）、指标→来源项。失败主因 fail-closed：**悬空引用**（refType=1 目标不在
+  快照/引用方不在快照/指标来源缺失/表达式标识符无节点）、**实例化失败**（本期占位语义=
+  表达式结构可解析+白名单 DELTA 可引用/INTEGRAL 不开放/表达式与引用边一致性——真
+  Aviator 归 FEAT-0012）、**循环依赖**（0036 FormulaCycleDetector 同款 DFS——快照侧
+  再验一道防御纵深）、节点键冲突（fullKey/metricCode 重复）。
+- **切换语义**：新图构建成功才原子换入 GraphHolder（引用替换，读者无中间态）；失败保持
+  旧图持续可用并 **ACK 回执失败**（ack_status=2 + errorMsg——REQ-0020「状态页显示新
+  版本构建失败及原因」数据源）；对账幂等（同版本同哈希跳过不重复回执）；同版本哈希漂移
+  探测（保持旧图+回执失败）；版本回归跳过。回执闭环断裂（ACK 未受理）计数告警可见。
+- **对账驱动**：启动全量拉取 + 可配周期对账（默认 300s）；config.changed 订阅缝占位
+  （通知只作触发信号——真订阅归 TD-0057，NotifySender 真联调归 TD-0056）。
+

+## 边界
+
+- 执行器/算子（TASK-0041/0042）、iot_calc_log/state 写（0041+/0063）、st_metric_value
+  （0045）、状态判定（0049）不在本工程；本工程交付「快照消费 → 依赖图 → 原子切换 →
+  ACK 闭环」，依赖图与拓扑序即 0041 的消费面。
+- `/calc/v1/status` 为观测口（无鉴权，内网面）；`/internal/v1/**` 是 §3.3/§3.4 契约
+  命名空间，本工程刻意不占用。

+  建为输入节点，不判悬空。
+- 三份冻结契约（统一消息模型 / 快照 Schema / 超级表结构，CONV-03）冻结后不擅自扩字段；
+  发现契约问题报告并停。

+ * 截断痕迹置尾）。业务码 200 = 已受理（data true/false 都是受理——false=过期失败回执
+ * 忽略/终态不倒退，非错误）；非 200 或网络失败 → false（调用方计数告警）。

+ * @author dowei
+ * @date 2026-11-23
+ */

+
+    /** errorMsg 上限（backend AckForm @Size(max=1000)） */
+    static final int ERROR_MSG_MAX = 1000;
+
+    /** 单次回执超时（拉取侧 TIMEOUT 同口径） */
+    private static final Duration TIMEOUT = Duration.ofSeconds(10);
+
+    private static final JsonMapper MAPPER = JsonMapper.builder().build();
+
+    private final String baseUrl;
+    private final String internalToken;
+    private final HttpClient http;
+
+    public HttpAckSender(String baseUrl, String internalToken) {
+        String trimmed = baseUrl == null ? "" : baseUrl.trim();
+        if (trimmed.isEmpty()) {
+            throw new IllegalArgumentException("backendBaseUrl 空白（CALC_BACKEND_BASE_URL 未配置）");
+        }
+        this.baseUrl = trimmed.endsWith("/") ? trimmed.substring(0, trimmed.length() - 1) : trimmed;
+        this.internalToken = internalToken;
+        this.http = HttpClient.newBuilder().connectTimeout(Duration.ofSeconds(10)).build();
+    }
+
+    @Override
+    public boolean send(AckCommand command) {
+        try {
+            Map<String, Object> payload = new LinkedHashMap<>();
+            payload.put("scopeType", command.scopeType());
+            payload.put("scopeId", command.scopeId());
+            payload.put("version", command.version());
+            payload.put("targetType", command.targetType());
+            payload.put("targetId", command.targetId());
+            payload.put("ackStatus", command.ackStatus());
+            if (command.errorMsg() != null) {
+                // AckForm @Size(max=1000)——超限截断（fail-soft，截断痕迹置尾）
+                String msg = command.errorMsg();
+                payload.put("errorMsg", msg.length() <= ERROR_MSG_MAX
+                        ? msg : msg.substring(0, ERROR_MSG_MAX - 3) + "...");
+            }
+            String body = MAPPER.writeValueAsString(payload);
+            HttpRequest request = HttpRequest.newBuilder()
+                    .uri(URI.create(baseUrl + "/internal/v1/config/ack"))
+                    .timeout(TIMEOUT)
+                    .header("Content-Type", "application/json")
+                    .header("X-Internal-Token", internalToken == null ? "" : internalToken)
+                    .POST(HttpRequest.BodyPublishers.ofString(body, StandardCharsets.UTF_8))
+                    .build();
+            HttpResponse<String> response =
+                    http.send(request, HttpResponse.BodyHandlers.ofString(StandardCharsets.UTF_8));
+            if (response.statusCode() != 200) {
+                return false;
+            }
+            JsonNode root = MAPPER.readTree(response.body());
+            return root.path("code").asInt(-1) == 200;
+        } catch (java.io.IOException e) {
+            return false; // 网络/端点失败——回执闭环断裂由调用方计数告警可见，不打断对账主链
+        } catch (InterruptedException e) {
+            Thread.currentThread().interrupt();
+            return false;
+        } catch (tools.jackson.core.JacksonException e) {
+            return false;
+        }
+    }

+ * 引用图循环依赖检测器（TASK-0040——backend 0036 {@code FormulaCycleDetector} 同款
+ * 语义移植：onPath 栈 + 全局 done 集（探索完毕剪枝），最坏 O(V+E)；DFS 递归深度=

+ * <p>与 0036 的差异仅两点（用途不同、算法逐字同构）：
+ * <ol>
+ *   <li>键域：0036 用数据项 id（保存链单实例候选检测）；本检测器用节点键
+ *       （数据项 fullKey——快照侧全图重建，跨实例/汇总边同图）；</li>
+ *   <li>起点：0036 检测「本项可达自身」（候选替换边后可达性）；本检测器对全图任意
+ *       环报警（快照侧防御纵深——发布链已拦一道，此处再验）。</li>
+ * </ol>
+ *
+ * @author dowei
+ * @date 2026-11-23
+ */
+public final class CycleDetector {
+
+    private CycleDetector() {
+    }
+
+    /**
+     * 在有向图中检测任意环。
+     *
+     * @param edges 有向图（节点键 → 被引用节点键集；无出边的节点可缺键）
+     * @return 环上节点键序列（按引用方向，起点不重复收尾——0036 口径）；无环返回 null
+     */
+    public static List<String> findAnyCycle(Map<String, Set<String>> edges) {
+        Set<String> done = new HashSet<>();
+        for (String start : edges.keySet()) {
+            if (done.contains(start)) {
+                continue;
+            }
+            Deque<String> path = new ArrayDeque<>();
+            Set<String> onPath = new HashSet<>();
+            if (dfs(start, edges, path, onPath, done)) {
+                return new ArrayList<>(path);
+            }
+        }
+        return null;
+    }
+
+    /** DFS：path/onPath 为当前栈，done 为已探索无环节点（剪枝防重复子树） */
+    private static boolean dfs(String current, Map<String, Set<String>> edges,
+                               Deque<String> path, Set<String> onPath, Set<String> done) {
+        if (done.contains(current)) {
+            return false;
+        }
+        path.addLast(current);
+        onPath.add(current);
+        for (String next : edges.getOrDefault(current, Set.of())) {
+            if (onPath.contains(next)) {
+                // 回到当前栈上任一节点（next 可能不是本次 start——findAnyCycle 语义下
+                // 任意环即报警）：收尾到环入口，返回环序列
+                rewindToCycle(path, next);
+                return true;
+            }
+            if (dfs(next, edges, path, onPath, done)) {
+                return true;
+            }
+        }
+        path.removeLast();
+        onPath.remove(current);
+        done.add(current);
+        return false;
+    }
+
+    /** 将 path 截断为从 next（环入口）起的环序列（起点不重复收尾） */
+    private static void rewindToCycle(Deque<String> path, String cycleEntry) {
+        while (!path.isEmpty() && !path.peekFirst().equals(cycleEntry)) {
+            path.removeFirst();
+        }
+    }

+/**
+ * 公式表达式占位校验器（TASK-0040 brief 决策 3：本期「实例化」=表达式结构可解析 +
+ * 白名单校验；真 Aviator 解析/求值归 FEAT-0012——本类是快照侧 fail-closed 的第一道
+ * 结构闸，不求值、不绑定运行时）。
+ *
+ * <p>白名单占位语义：{@code DELTA} 可引用（1 参）；{@code INTEGRAL} 不开放手写
+ * （FEAT-0013 业务规则——内置算子手写禁用）；其余函数一律拒绝。
+ *
+ * <p>结构口径（token 级）：标识符含点（fullKey 形态）；操作数/运算符交替；括号配对；
+ * 函数调用参数数校验（DELTA=1）；三元与逻辑比较运算符放行（结构位合法即可）。
+ * 标识符集随结果返回（供 GraphBuilder 与引用边一致性比对——防御纵深）。
+ *
+ * @author dowei
+ * @date 2026-11-23
+ */
+public final class FormulaExpressionValidator {
+
+    /** 白名单：函数名 → 参数数（-1 = 不定参；本期仅 DELTA 可引用） */
+    private static final java.util.Map<String, Integer> WHITELIST = java.util.Map.of("DELTA", 1);
+
+    /** 显式禁用函数（错误信息直达口径） */
+    private static final java.util.Set<String> BANNED = java.util.Set.of("INTEGRAL");
+
+    private FormulaExpressionValidator() {
+    }
+
+    /**
+     * 校验结果。
+     *
+     * @param ok          结构可解析且白名单通过
+     * @param error       失败原因（ok=false 时非空）
+     * @param identifiers 表达式中被引用的标识符（出现序去重——fullKey/点位编码）
+     */
+    public record ExpressionCheck(boolean ok, String error, List<String> identifiers) {
+
+        public static ExpressionCheck fail(String error) {
+            return new ExpressionCheck(false, error, List.of());
+        }
+    }
+
+    /**
+     * 校验公式表达式结构与白名单。
+     *
+     * @param formula 公式原文（sourceType=2 数据项的 formula 字段）
+     * @return 校验结果（永不返回 null；空白公式=失败）
+     */
+    public static ExpressionCheck validate(String formula) {
+        if (formula == null || formula.isBlank()) {
+            return ExpressionCheck.fail("公式空白（sourceType=2 必须有表达式）");
+        }
+        List<String> tokens = tokenize(formula);
+        if (tokens == null) {
+            return ExpressionCheck.fail("词法失败（非法字符/悬空点标识符）: " + formula);
+        }
+        return parseTokenFlow(tokens, formula);
+    }
+
+    // ---------- 词法 ----------
+
+    /** 标量 token：操作数（数字/标识符）、运算符、括号、逗号、函数名 */
+    private record Token(String text, boolean function) {
+    }
+
+    /**
+     * 词法切分：数字（含小数）、标识符（含点——fullKey 形态；悬空点拒绝）、运算符。
+     * 标识符后紧跟 '(' 判定为函数名 token。
+     */
+    private static List<String> tokenize(String formula) {
+        List<String> tokens = new ArrayList<>();
+        int i = 0;
+        int n = formula.length();
+        while (i < n) {
+            char c = formula.charAt(i);
+            if (Character.isWhitespace(c)) {
+                i++;
+                continue;
+            }
+            if (Character.isDigit(c)
+                    || (c == '.' && i + 1 < n && Character.isDigit(formula.charAt(i + 1)))) {
+                int start = i;
+                boolean sawDot = false;
+                while (i < n && (Character.isDigit(formula.charAt(i)) || formula.charAt(i) == '.')) {
+                    if (formula.charAt(i) == '.') {
+                        if (sawDot) {
+                            return null;
+                        }
+                        sawDot = true;
+                    }
+                    i++;
+                }
+                tokens.add("num:" + formula.substring(start, i));
+                continue;
+            }
+            if (Character.isJavaIdentifierStart(c)) {
+                int start = i;
+                while (i < n && (Character.isJavaIdentifierPart(c = formula.charAt(i)) || c == '.')) {
+                    i++;
+                }
+                String ident = formula.substring(start, i);
+                if (ident.endsWith(".")) {
+                    return null; // 悬空点标识符（fullKey 形态不允许）
+                }
+                // 函数名：紧随 '('（中间不允许空白——DELTA( 同源形态）
+                boolean isFunction = i < n && formula.charAt(i) == '(';
+                tokens.add(isFunction ? "fn:" + ident : ident);
+                continue;
+            }
+            if ("+-*/%(),?:<>!&|=".indexOf(c) >= 0) {
+                // 双字符运算符（&& || >= <= == !=）
+                if (i + 1 < n) {
+                    String two = formula.substring(i, i + 2);
+                    if (two.equals("&&") || two.equals("||") || two.equals(">=") || two.equals("<=")
+                            || two.equals("==") || two.equals("!=")) {
+                        tokens.add(two);
+                        i += 2;
+                        continue;
+                    }
+                }
+                tokens.add(String.valueOf(c));
+                i++;
+                continue;
+            }
+            return null; // 非法字符
+        }
+        return tokens;
+    }
+
+    // ---------- 语法（状态机：操作数/运算符交替 + 括号配对 + 函数白名单） ----------
+
+    /** 运算符/结构符号集（expectOperand 位出现即结构错误） */
+    private static final java.util.Set<String> OPERATORS = java.util.Set.of(
+            "+", "-", "*", "/", "%", ",", "?", ":", ">", "<", ">=", "<=", "==", "!=", "&&", "||",
+            "!", "(", ")");
+
+    /** state=true 期望操作数（一元位）；state=false 期望运算符/闭括号/逗号/三元冒号 */
+    private static ExpressionCheck parseTokenFlow(List<String> tokens, String formula) {
+        boolean expectOperand = true;
+        java.util.Deque<int[]> parens = new java.util.ArrayDeque<>();
+        // 函数参数计数：parens 元素 {isFunction, argCount, 已收参-1}（非函数括号 isFunction=0；
+        // 三元层 argCount=-1 配对冒号）
+        java.util.Set<String> seen = new java.util.LinkedHashSet<>();
+
+        int i = 0;
+        while (i < tokens.size()) {
+            String token = tokens.get(i);
+            if (expectOperand) {
+                if (token.startsWith("num:")) {
+                    expectOperand = false;
+                } else if (token.startsWith("fn:")) {
+                    String fn = token.substring(3);
+                    if (BANNED.contains(fn)) {
+                        return ExpressionCheck.fail("内置算子 " + fn + " 不开放手写（FEAT-0013 业务规则）");
+                    }
+                    Integer argCount = WHITELIST.get(fn);
+                    if (argCount == null) {
+                        return ExpressionCheck.fail("未知函数 " + fn + "（白名单: DELTA；真 Aviator 归 FEAT-0012）");
+                    }
+                    parens.push(new int[] {1, argCount, 0});
+                    i++;                  // 越过函数名 token，落在 '('
+                    if (i >= tokens.size()) {
+                        return ExpressionCheck.fail("函数 " + fn + " 调用未闭合（缺括号）");
+                    }
+                    if (!tokens.get(i).equals("(")) {
+                        return ExpressionCheck.fail("函数 " + fn + " 后缺调用括号: " + formula);
+                    }
+                    if (i + 1 >= tokens.size()) {
+                        return ExpressionCheck.fail("函数 " + fn + " 调用未闭合");
+                    }
+                    if (tokens.get(i + 1).equals(")")) {
+                        return ExpressionCheck.fail("函数 " + fn + " 参数不足（须 " + argCount + " 参）");
+                    }
+                    i++;                  // 消费 '('，指向第一个参数 token
+                    continue;
+                } else if (token.equals("(")) {
+                    parens.push(new int[] {0, 0, 0});
+                } else if (token.equals("!") || token.equals("-") || token.equals("+")) {
+                    // 一元位合法（!x / -x / +x）——保持 expectOperand
+                } else if (token.equals(")")) {
+                    return ExpressionCheck.fail("空操作数/多余闭括号: " + formula);
+                } else if (OPERATORS.contains(token)) {
+                    return ExpressionCheck.fail("期望操作数，得运算符 " + token + ": " + formula);
+                } else {
+                    // 标识符（操作数）
+                    seen.add(token);
+                    expectOperand = false;
+                }
+            } else {
+                switch (token) {
+                    case "+", "-", "*", "/", "%", ">", "<", ">=", "<=", "==", "!=", "&&", "||" ->
+                        expectOperand = true;
+                    case "," -> {
+                        if (parens.isEmpty() || parens.peek()[0] != 1) {
+                            return ExpressionCheck.fail("逗号出现在函数调用外: " + formula);
+                        }
+                        parens.peek()[2]++;
+                        expectOperand = true;
+                    }
+                    case "?" -> {
+                        parens.push(new int[] {0, -1, 0}); // 三元括号层（冒号配对用）
+                        expectOperand = true;
+                    }
+                    case ":" -> {
+                        if (parens.isEmpty() || parens.peek()[0] != 0 || parens.peek()[1] != -1) {
+                            return ExpressionCheck.fail("三元冒号无配对 ?: " + formula);
+                        }
+                        parens.pop();
+                        expectOperand = true;
+                    }
+                    case ")" -> {
+                        if (parens.isEmpty()) {
+                            return ExpressionCheck.fail("括号不平衡（多余 ')'）: " + formula);
+                        }
+                        int[] frame = parens.pop();
+                        if (frame[0] == 1 && frame[2] + 1 != frame[1]) {
+                            return ExpressionCheck.fail("函数参数数不符（须 " + frame[1]
+                                    + " 参，实际 " + (frame[2] + 1) + "）: " + formula);
+                        }
+                        if (frame[1] == -1) {
+                            return ExpressionCheck.fail("三元 ? 无配对冒号: " + formula);
+                        }
+                    }
+                    default -> {
+                        return ExpressionCheck.fail("相邻操作数（缺运算符）: " + formula + " @ " + token);
+                    }
+                }
+            }
+            i++;
+        }
+        if (expectOperand) {
+            return ExpressionCheck.fail("结尾悬空（缺操作数）: " + formula);
+        }
+        if (!parens.isEmpty()) {
+            return ExpressionCheck.fail("括号不平衡（未闭合）: " + formula);
+        }
+        return new ExpressionCheck(true, null, List.copyOf(seen));
+    }
+}

+ *
+ * <p>构建口径：节点=数据项/指标全键（点位以编码为键）；边=引用（公式→上游数据项/
+ * 指标；汇总→子级）——

+ *   <li>引用边：iot_data_item_ref 行——refType=1 → 数据项全键（目标不在快照即

+ *       "."+dataCode 结构派生，实例层级由 instance_code 路径前缀表达——快照不含模型

+    /**
+     * 从快照体构建依赖图。
+     *
+     * @param body 已过契约校验的快照体
+     * @return 依赖图（不可变；拓扑序完备）
+     * @throws GraphBuildException 悬空引用/实例化失败/循环依赖/节点键冲突

+    public DependencyGraph build(SnapshotBody body) {
+        // ① 数据项节点（fullKey 唯一 + fullKey=instanceCode+"."+dataCode 结构派生）
+        Map<String, GraphNode> nodes = new LinkedHashMap<>();
+        Map<Long, DataItem> itemById = new LinkedHashMap<>();

+            String ctx = "dataItems(id=" + item.getId() + ", fullKey=" + item.getFullKey() + ")";
+            if (itemByFullKey.containsKey(item.getFullKey())) {
+                throw new GraphBuildException(FailureReason.DUPLICATE_NODE,
+                        "节点键冲突: fullKey=" + item.getFullKey()

+                                + " 与 id=" + item.getId());
+            }

+            itemByFullKey.put(item.getFullKey(), item);

+                throw new GraphBuildException(FailureReason.INSTANTIATION_FAILED,
+                        "非公式项携带公式: fullKey=" + item.getFullKey() + " sourceType="
+                                + item.getSourceType());

+                edges.addAll(buildRefEdges(item, refs, itemById, nodes));

+        }

+        // （公式项边=表达式校验通过后统一构建，见下）。

+            if (edge.type() == EdgeType.FORMULA_REF || edge.type() == EdgeType.ROLLUP) {
+                refGraph.computeIfAbsent(edge.from(), k -> new LinkedHashSet<>()).add(edge.to());
+            }
+        }
+        List<String> cycle = CycleDetector.findAnyCycle(refGraph);

+    private List<GraphEdge> buildRefEdges(DataItem item, List<FormulaRef> refs,
+                                          Map<Long, DataItem> itemById,
+                                          Map<String, GraphNode> nodes) {
+        List<GraphEdge> out = new ArrayList<>(refs.size());
+        for (FormulaRef ref : refs) {

+            if (owner == null) {
+                throw new GraphBuildException(FailureReason.DANGLING_REF,
+                        "悬空引用: 引用边 id=" + ref.getId() + " 的引用方 itemId=" + ref.getItemId()
+                                + " 不在快照");
+            }
+            if (ref.getRefType() != null && ref.getRefType() == 2) {

+                nodes.putIfAbsent(ref.getRefFullKey(),

+                out.add(new GraphEdge(item.getFullKey(), ref.getRefFullKey(), EdgeType.POINT_REF,
+                        "ref#" + ref.getId()));
+            } else {
+                if (!itemByFullKeyContains(nodes, ref.getRefFullKey())) {

+                            "悬空引用: ref#" + ref.getId() + " " + item.getFullKey() + " -> "
+                                    + ref.getRefFullKey() + "（引用目标不在快照——上游逻辑删未清边或装载缺失）");
+                }
+                out.add(new GraphEdge(item.getFullKey(), ref.getRefFullKey(), EdgeType.FORMULA_REF,
+                        "ref#" + ref.getId()));
+            }
+        }

+    }

+     * （parentCode + "." 前缀）且 dataCode 相同且非自身。空子级合法（运行期打码 7，REQ-0017）。

+    private List<GraphEdge> buildRollupEdges(DataItem rollup, SnapshotBody body) {

+    /** 指标边（metricCode → 来源数据项；比值型分子/分母两源） */
+    private List<GraphEdge> buildMetricEdges(Metric metric, Map<Long, DataItem> itemById,
+                                             Map<String, GraphNode> nodes) {
+        List<GraphEdge> out = new ArrayList<>();
+        nodes.putIfAbsent(metric.getMetricCode(),
+                new GraphNode(metric.getMetricCode(), NodeKind.METRIC, null));
+        appendMetricEdge(metric, metric.getSourceItemId(), "source", itemById, out);
+        if (metric.getAggType() != null && metric.getAggType() == 5) {
+            appendMetricEdge(metric, metric.getRatioNumItemId(), "ratioNum", itemById, out);
+            appendMetricEdge(metric, metric.getRatioDenItemId(), "ratioDen", itemById, out);

+    private void appendMetricEdge(Metric metric, Long itemId, String slot,
+                                  Map<Long, DataItem> itemById, List<GraphEdge> out) {
+        if (itemId == null) {
+            if ("source".equals(slot) || "ratioNum".equals(slot)) {
+                // sourceItemId 比值型可空（契约）；非比值 source 缺失=无法实例化
+                if ("source".equals(slot) && metric.getAggType() != null && metric.getAggType() != 5) {
+                    throw new GraphBuildException(FailureReason.INSTANTIATION_FAILED,
+                            "指标实例化失败: metricCode=" + metric.getMetricCode()
+                                    + " 非比值型缺 sourceItemId");
+                }
+                if ("ratioNum".equals(slot)) {
+                    throw new GraphBuildException(FailureReason.INSTANTIATION_FAILED,
+                            "指标实例化失败: metricCode=" + metric.getMetricCode()
+                                    + " 比值型缺 ratioNumItemId");
+                }
+            }
+            return;
+        }
+        DataItem item = itemById.get(itemId);
+        if (item == null) {
+            throw new GraphBuildException(FailureReason.DANGLING_REF,
+                    "悬空引用: 指标 " + metric.getMetricCode() + " 的 " + slot + " itemId="
+                            + itemId + " 不在快照");
+        }
+        out.add(new GraphEdge(metric.getMetricCode(), item.getFullKey(), EdgeType.METRIC_SOURCE,
+                "metric#" + metric.getId() + ":" + slot));
+    }
+
+    // ---------- 内部步骤 ----------
+
+    /** fullKey → instanceCode 剥离（fullKey = instanceCode + "." + dataCode 契约结构） */
+    static String instanceCodeOf(String fullKey, String dataCode, String ctx) {
+        String suffix = "." + dataCode;
+        if (fullKey == null || dataCode == null || !fullKey.endsWith(suffix)
+                || fullKey.length() <= suffix.length()) {
+            throw new GraphBuildException(FailureReason.INSTANTIATION_FAILED,
+                    "fullKey 结构不符（须 instanceCode + \".\" + dataCode）: " + ctx);
+        }
+        return fullKey.substring(0, fullKey.length() - suffix.length());
+    }
+
+    /** 拓扑序：被依赖者在前；留有未输出节点即内部矛盾（环已拦截——防御性再验一道） */
+    static List<String> topoSort(Map<String, GraphNode> nodes, List<GraphEdge> edges) {
+        Map<String, Integer> unresolved = new LinkedHashMap<>();
+        for (String key : nodes.keySet()) {
+            unresolved.put(key, 0);
+        }
+        Map<String, List<String>> dependents = new LinkedHashMap<>();
+        for (GraphEdge edge : edges) {
+            // from 依赖 to：to 先输出；from 的未决依赖数 = 出边数
+            unresolved.merge(edge.from(), 1, Integer::sum);
+            dependents.computeIfAbsent(edge.to(), k -> new ArrayList<>()).add(edge.from());
+        }
+        List<String> order = new ArrayList<>(nodes.size());
+        List<String> ready = new ArrayList<>();
+        for (String key : nodes.keySet()) {
+            if (unresolved.get(key) == 0) {
+                ready.add(key);
+            }
+        }
+        while (!ready.isEmpty()) {
+            // 取队首（插入序——确定性=快照装载序）
+            String key = ready.remove(0);
+            order.add(key);
+            for (String dependent : dependents.getOrDefault(key, List.of())) {
+                int left = unresolved.merge(dependent, -1, Integer::sum);
+                if (left == 0) {
+                    ready.add(dependent);
+                }
+            }
+        }
+        if (order.size() != nodes.size()) {
+            List<String> leftover = new ArrayList<>(nodes.keySet());
+            leftover.removeAll(order);
+            throw new IllegalStateException("拓扑序不完备（构建期环检测漏报——内部矛盾）: " + leftover);
+        }
+        return order;
+    }
+
+    /** 节点 → 上游依赖键集（0041 执行器消费） */
+    static Map<String, Set<String>> dependenciesOf(Map<String, GraphNode> nodes,
+                                                   List<GraphEdge> edges) {
+        Map<String, Set<String>> out = new LinkedHashMap<>();
+        for (String key : nodes.keySet()) {
+            out.put(key, new LinkedHashSet<>());
+        }
+        for (GraphEdge edge : edges) {
+            out.computeIfAbsent(edge.from(), k -> new LinkedHashSet<>()).add(edge.to());
+        }
+        return out;
+    }
+}

+                    lastAttempt = LastAttempt.success(version, clock.instant());

+                }
+                // 同版本哈希漂移：存储被篡改/端点异常探测（§3.3「校验哈希」对账口径）
+                counters.incFetchFailures();
+                lastAttempt = LastAttempt.failure(version, "同版本哈希漂移 last="
+                        + current.hash() + " got=" + hash, clock.instant());
+                log.error("[CALC-RECONCILE] 同版本哈希漂移 version={} last={} got={}——保持旧图并回执失败",
+                        version, current.hash(), hash);
+                ackFailure(version, "同版本哈希漂移（存储被篡改/端点异常探测）last=" + current.hash()
+                        + " got=" + hash);
+                return;
+            }
+        }
+
+        // 新版本（或首拉）：解析 → 构建 → 原子切换；失败保持旧图 + ACK 失败
+        try {
+            SnapshotBody body = parser.parse(fetched.bodyJson());
+            DependencyGraph graph = builder.build(body);
+            holder.switchTo(new AppliedGraph(version, hash, graph, clock.instant()));
+            counters.incReplaced();
+            lastAttempt = LastAttempt.success(version, clock.instant());
+            log.info("[CALC-RECONCILE] 依赖图已切换 version={} hash={} nodes={} edges={} topo={}",
+                    version, hash, graph.nodeCount(), graph.edgeCount(), graph.getTopoOrder().size());
+            ackEffective(version);
+        } catch (RuntimeException e) {
+            counters.incBuildFailures();
+            String reason = e.getMessage() == null ? e.getClass().getSimpleName() : e.getMessage();
+            lastAttempt = LastAttempt.failure(version, reason, clock.instant());
+            log.error("[CALC-RECONCILE] 新版本构建失败（保持旧图 version={} 继续可用）version={} 原因: {}",
+                    current == null ? "-" : current.version(), version, reason);
+            ackFailure(version, (e instanceof GraphBuildException gbe
+                    ? "依赖图构建失败(" + gbe.getReason() + "): " : "快照解析/构建失败: ") + reason);
+        }
+    }
+
+    /** ACK 生效（ackStatus=1；任意旧态可置 1——失败后补生效是正常恢复路径） */
+    private void ackEffective(long version) {
+        boolean delivered = ackSender.send(new AckCommand(version, 1, null,
+                TARGET_TYPE_CALC, properties.getTargetId(), SCOPE_COMPUTE, SCOPE_COMPUTE_ID));
+        if (delivered) {
+            counters.incAckOk();
+            log.info("[CALC-RECONCILE] ACK 生效已回执 version={} targetType=3 targetId={}",
+                    version, properties.getTargetId());
+        } else {
+            counters.incAckFail();
+            log.error("[CALC-RECONCILE] ACK 生效回执未受理 version={}（回执闭环断裂——计数告警）", version);
+        }
+    }
+
+    /** ACK 失败（ackStatus=2 + errorMsg——REQ-0020「状态页显示构建失败及原因」数据源） */

+/**
+ * SHA-256 十六进制摘要工具（快照哈希可重算校验用——TASK-0040 brief 决策 2：
+ * BUG-0005 修复后出站体=原始字节，重算 SHA-256 == snapshotHash，不一致 fail-closed）。
+ *
+ * @author dowei
+ * @date 2026-11-23

+
+    private Hashes() {
+    }
+
+    /** SHA-256 → 64 位小写十六进制（与 backend SnapshotStorage.sha256Hex 同口径） */
+    public static String sha256Hex(byte[] bytes) {
+        MessageDigest digest;
+        try {
+            digest = MessageDigest.getInstance("SHA-256");
+        } catch (NoSuchAlgorithmException e) {
+            throw new IllegalStateException("SHA-256 不可用", e);
+        }
+        byte[] out = digest.digest(bytes);
+        StringBuilder sb = new StringBuilder(out.length * 2);
+        for (byte b : out) {
+            sb.append(Character.forDigit((b >> 4) & 0xF, 16));
+            sb.append(Character.forDigit(b & 0xF, 16));
+        }
+        return sb.toString();
+    }
+
+    /** UTF-8 字符串摘要（快照体文本哈希便捷入口） */
+    public static String sha256Hex(String text) {
+        return sha256Hex(text.getBytes(StandardCharsets.UTF_8));
+    }

+    private void checkHashForm(String hash, long version) {
+        if (hash == null || hash.length() != 64) {
+            throw new SnapshotFetchException("snapshot: 快照哈希形态非法（snapshotHash 须 64 位小写 hex）"
+                    + " version=" + version + " got=" + hash);
+        }
+        for (int i = 0; i < hash.length(); i++) {
+            char c = hash.charAt(i);
+            if ((c < '0' || c > '9') && (c < 'a' || c > 'f')) {
+                throw new SnapshotFetchException("snapshot: 快照哈希形态非法（snapshotHash 须 64 位小写 hex）"
+                        + " version=" + version + " got=" + hash);
+            }
+        }
+    }

+/**
+ * 原始 JSON 值提取器（TASK-0040 哈希可重算校验的基石）。
+ *
+ * <p>端点响应 = Result&lt;InternalSnapshotVO&gt; 信封，data.snapshot 为 Jackson 3
+ * {@code RawValue} <b>原始存储字节透传</b>（BUG-0005 修复后形态）。要重算 SHA-256 与
+ * snapshotHash 恒一致，必须拿到 snapshot 值在响应文本中的<b>逐字节原文</b>——任何
+ * 「解析成树再序列化」都会改写数字形态（5.000000→5.0，TASK-0027 live 实证的 BUG-0005
+ * 病灶）。本提取器在响应文本上做字符串感知的平衡扫描（字符串/转义/嵌套结构不破坏
+ * 配对），返回值的原文子串。
+ *
+ * @author dowei
+ * @date 2026-11-23
+ */
+public final class RawJsonExtractor {
+
+    private RawJsonExtractor() {
+    }
+
+    /**
+     * 按路径提取 JSON 值的原文子串。
+     *
+     * @param json 响应原文（UTF-8 文本）
+     * @param path 键路径（如 "data", "snapshot"）
+     * @return 值的原文（对象/数组含配对花括号/方括号；标量为字面量；字符串含引号）
+     * @throws IllegalArgumentException JSON 解析失败或路径未命中
+     */
+    public static String extract(String json, String... path) {
+        if (json == null) {
+            throw new IllegalArgumentException("json 为 null");
+        }
+        if (path == null || path.length == 0) {
+            throw new IllegalArgumentException("path 为空");
+        }
+        Cursor cursor = new Cursor(json);
+        cursor.skipWhitespace();
+        if (cursor.peek() != '{') {
+            throw new IllegalArgumentException("响应非 JSON 对象: " + cursor.snippet());
+        }
+        for (int depth = 0; depth < path.length; depth++) {
+            String want = path[depth];
+            String value = readObjectValueForKey(cursor, want, String.join(".", subPath(path, depth)));
+            if (depth == path.length - 1) {
+                return value;
+            }
+            // 中间段：值必须是对象，下钻
+            String trimmed = value.trim();
+            if (trimmed.isEmpty() || trimmed.charAt(0) != '{') {
+                throw new IllegalArgumentException("路径 " + String.join(".", subPath(path, depth + 1))
+                        + " 前值非对象: " + preview(value));
+            }
+            cursor = new Cursor(trimmed);
+            cursor.skipWhitespace();
+        }
+        throw new IllegalArgumentException("路径未命中");
+    }
+
+    private static String[] subPath(String[] path, int to) {
+        String[] out = new String[to + 1];
+        System.arraycopy(path, 0, out, 0, to + 1);
+        return out;
+    }
+
+    /** 在（已定位 '{' 的）对象上读取指定键的值原文，并推进 cursor 到该值之后 */
+    private static String readObjectValueForKey(Cursor cursor, String key, String ctx) {
+        if (cursor.peek() != '{') {
+            throw new IllegalArgumentException(ctx + ": 期望对象得到 " + preview(String.valueOf(cursor.peek())));
+        }
+        cursor.advance(); // '{'
+        cursor.skipWhitespace();
+        if (cursor.peek() == '}') {
+            cursor.advance();
+            throw new IllegalArgumentException(ctx + ": 键 " + key + " 未命中（空对象）");
+        }
+        while (true) {
+            cursor.skipWhitespace();
+            if (cursor.peek() != '"') {
+                throw new IllegalArgumentException(ctx + ": 对象键应以引号开始: " + cursor.snippet());
+            }
+            String name = cursor.readString();
+            cursor.skipWhitespace();
+            if (cursor.peek() != ':') {
+                throw new IllegalArgumentException(ctx + ": 键后应有冒号: " + cursor.snippet());
+            }
+            cursor.advance();
+            cursor.skipWhitespace();
+            int start = cursor.pos;
+            cursor.skipValue();
+            if (name.equals(key)) {
+                return cursor.text.substring(start, cursor.pos);
+            }
+            cursor.skipWhitespace();
+            char next = cursor.peek();
+            if (next == ',') {
+                cursor.advance();
+                continue;
+            }
+            if (next == '}') {
+                cursor.advance();
+                throw new IllegalArgumentException(ctx + ": 键 " + key + " 未命中");
+            }
+            throw new IllegalArgumentException(ctx + ": 期望 ',' 或 '}': " + cursor.snippet());
+        }
+    }
+
+    private static String preview(String s) {
+        if (s == null) {
+            return "null";
+        }
+        String t = s.length() > 48 ? s.substring(0, 48) + "..." : s;
+        return t.replace("\n", "\\n");
+    }
+
+    /** 文本游标：字符串感知的推进/跳读 */
+    private static final class Cursor {
+        final String text;
+        int pos;
+
+        Cursor(String text) {
+            this.text = text;
+        }
+
+        char peek() {
+            if (pos >= text.length()) {
+                throw new IllegalArgumentException("JSON 意外结束: " + snippet());
+            }
+            return text.charAt(pos);
+        }
+
+        void advance() {
+            pos++;
+        }
+
+        void skipWhitespace() {
+            while (pos < text.length() && Character.isWhitespace(text.charAt(pos))) {
+                pos++;
+            }
+        }
+
+        /** 读取引号字符串（处理转义；返回去引号原文——匹配键名用） */
+        String readString() {
+            if (peek() != '"') {
+                throw new IllegalArgumentException("期望字符串: " + snippet());
+            }
+            StringBuilder sb = new StringBuilder();
+            pos++; // 开引号
+            while (true) {
+                if (pos >= text.length()) {
+                    throw new IllegalArgumentException("字符串未闭合: " + snippet());
+                }
+                char c = text.charAt(pos);
+                if (c == '"') {
+                    pos++;
+                    return sb.toString();
+                }
+                if (c == '\\') {
+                    pos++;
+                    if (pos >= text.length()) {
+                        throw new IllegalArgumentException("转义未闭合: " + snippet());
+                    }
+                    char esc = text.charAt(pos);
+                    switch (esc) {
+                        case '"' -> sb.append('"');
+                        case '\\' -> sb.append('\\');
+                        case '/' -> sb.append('/');
+                        case 'b' -> sb.append('\b');
+                        case 'f' -> sb.append('\f');
+                        case 'n' -> sb.append('\n');
+                        case 'r' -> sb.append('\r');
+                        case 't' -> sb.append('\t');
+                        case 'u' -> {
+                            if (pos + 4 >= text.length()) {
+                                throw new IllegalArgumentException("\\u 转义不完整: " + snippet());
+                            }
+                            sb.append((char) Integer.parseInt(text.substring(pos + 1, pos + 5), 16));
+                            pos += 4;
+                        }
+                        default -> throw new IllegalArgumentException("未知转义 \\" + esc + ": " + snippet());
+                    }
+                    pos++;
+                    continue;
+                }
+                sb.append(c);
+                pos++;
+            }
+        }
+
+        /** 跳过一个完整 JSON 值（字符串感知的平衡配对），pos 停在值结束后 */
+        void skipValue() {
+            skipWhitespace();
+            char c = peek();
+            switch (c) {
+                case '"' -> {
+                    readString();
+                }
+                case '{', '[' -> {
+                    int depth = 0;
+                    while (true) {
+                        if (pos >= text.length()) {
+                            throw new IllegalArgumentException("结构未闭合: " + snippet());
+                        }
+                        char ch = text.charAt(pos);
+                        if (ch == '"') {
+                            readString();
+                            continue;
+                        }
+                        if (ch == '{' || ch == '[') {
+                            depth++;
+                        } else if (ch == '}' || ch == ']') {
+                            depth--;
+                            if (depth == 0) {
+                                pos++;
+                                return;
+                            }
+                        }
+                        pos++;
+                    }
+                }
+                default -> {
+                    // 标量：读到结构性边界（, } ]）或空白
+                    while (pos < text.length()) {
+                        char ch = text.charAt(pos);
+                        if (ch == ',' || ch == '}' || ch == ']' || Character.isWhitespace(ch)) {
+                            return;
+                        }
+                        pos++;
+                    }
+                }
+            }
+        }
+
+        String snippet() {
+            int from = Math.max(0, pos - 24);
+            int to = Math.min(text.length(), pos + 24);
+            return preview(text.substring(from, to));
+        }
+    }

+    private static final Set<String> DATA_ITEM_REQUIRED = Set.of(

+    private static final Set<String> METRIC_REQUIRED = Set.of(
+            "id", "tenantId", "metricCode", "metricName", "instanceId", "aggType", "period");

+    /** 点位/通道对象：形状校验所需最小契约集（非消费面——仅 required 校验） */
+    private static final Set<String> POINT_REQUIRED = Set.of(
+            "id", "tenantId", "pointCode", "pointName", "dataType", "valueType");

+            "id", "tenantId", "gatewayId", "channelCode", "channelName", "protocolType",

+    private static final tools.jackson.databind.json.JsonMapper MAPPER =

+    /**
+     * 解析并校验快照体。
+     *
+     * @param bodyJson 快照体原文（哈希重算通过的原始字节域文本）
+     * @return 快照体模型（dataItems/formulas/metrics 绑定）
+     * @throws SnapshotFormatException 任一契约纪律违反

+    public SnapshotBody parse(String bodyJson) {
+        JsonNode root;
+        try {
+            root = MAPPER.readTree(bodyJson);
+        } catch (tools.jackson.core.JacksonException e) {
+            throw new SnapshotFormatException("快照体解析失败（非 JSON）: " + e.getMessage(), e);
+        }
+        if (root == null || !root.isObject()) {
+            throw new SnapshotFormatException("快照体须为 JSON 对象");
+        }
+        checkKeys(root, TOP_ALLOWED, TOP_REQUIRED, "顶层");
+
+        List<JsonNode> points = elementsOf(root, "points");
+        List<JsonNode> channels = elementsOf(root, "channels");
+        List<DataItem> dataItems = new ArrayList<>();
+        List<FormulaRef> formulas = new ArrayList<>();
+        List<Metric> metrics = new ArrayList<>();
+
+        List<JsonNode> itemNodes = elementsOf(root, "dataItems");
+        for (int i = 0; i < itemNodes.size(); i++) {
+            dataItems.add(bindDataItem(itemNodes.get(i), "dataItems[" + i + "]"));
+        }
+        List<JsonNode> refNodes = elementsOf(root, "formulas");
+        for (int i = 0; i < refNodes.size(); i++) {
+            formulas.add(bindFormula(refNodes.get(i), "formulas[" + i + "]"));
+        }
+        List<JsonNode> metricNodes = elementsOf(root, "metrics");
+        for (int i = 0; i < metricNodes.size(); i++) {
+            metrics.add(bindMetric(metricNodes.get(i), "metrics[" + i + "]"));
+        }
+        // 非消费面：形状校验后不进模型（派生规则 7——网关范围对象非 calc 消费面）
+        for (int i = 0; i < points.size(); i++) {
+            checkKeys(points.get(i), null, POINT_REQUIRED, "points[" + i + "]");
+        }
+        for (int i = 0; i < channels.size(); i++) {
+            checkKeys(channels.get(i), null, CHANNEL_REQUIRED, "channels[" + i + "]");
+        }
+        return new SnapshotBody(
+                root.get("schemaVersion").asString(),
+                root.get("tenantId").asLong(),
+                root.get("scopeType").asInt(),
+                root.get("scopeId").asLong(),
+                root.get("version").asLong(),
+                dataItems, formulas, metrics);
+    }

+    // ---------- 内部校验与绑定 ----------
+
+    /**
+     * 键纪律：required 存在性（缺失或显式 null 视为缺失）+ allowed 白名单
+     * （additionalProperties=false；allowed=null 仅做 required 校验——非消费面）。
+     */
+    void checkKeys(JsonNode obj, Set<String> allowed, Set<String> required, String ctx) {
+        if (!obj.isObject()) {
+            throw new SnapshotFormatException(ctx + ": 须为 JSON 对象");
+        }
+        List<String> missing = new ArrayList<>();
+        for (String key : required) {
+            JsonNode value = obj.get(key);
+            if (value == null || value.isNull()) {
+                missing.add(key);
+            }
+        }
+        if (!missing.isEmpty()) {
+            throw new SnapshotFormatException(ctx + ": 缺 required 字段 " + missing
+                    + "（additionalProperties=false 同层纪律）");
+        }
+        if (allowed == null) {
+            return;
+        }
+        List<String> unknown = new ArrayList<>();
+        obj.properties().forEach(entry -> {
+            if (!allowed.contains(entry.getKey())) {
+                unknown.add(entry.getKey());
+            }
+        });
+        if (!unknown.isEmpty()) {
+            throw new SnapshotFormatException(ctx + ": 未知字段 " + unknown
+                    + "（additionalProperties=false，演进走版本升版 CONV-03）");
+        }
+    }

+    private void validateDataItem(DataItem item, String ctx) {

+        checkFlag("status", item.getStatus(), ctx);
+    }

+                    + " 不在契约枚举内（HOUR/DAY/MONTH/YEAR）");

+        checkFlag("status", metric.getStatus(), ctx);

+        if (metric.getAggType() == 5 && metric.getRatioNumItemId() == null) {

+        }
+        return metric;

+    private List<JsonNode> elementsOf(JsonNode body, String field) {
+        JsonNode array = body.get(field);
+        if (array == null || array.isNull()) {
+            return List.of();
+        }
+        if (!array.isArray()) {
+            throw new SnapshotFormatException(field + ": 须为 JSON 数组");
+        }
+        List<JsonNode> out = new ArrayList<>();
+        array.forEach(out::add);
+        return out;
+    }
+
+    private static String asStringOrNull(JsonNode node, String key) {
+        JsonNode value = node.get(key);
+        return value == null || value.isNull() ? null : value.asString();
+    }
+
+    private static Long asLongOrNull(JsonNode node, String key) {
+        JsonNode value = node.get(key);
+        return value == null || value.isNull() ? null : value.asLong();
+    }
+
+    private static Integer asIntOrNull(JsonNode node, String key) {
+        JsonNode value = node.get(key);
+        return value == null || value.isNull() ? null : value.asInt();
+    }
+
+    private static Double asDoubleOrNull(JsonNode node, String key) {
+        JsonNode value = node.get(key);
+        if (value == null || value.isNull()) {
+            return null;
+        }
+        if (!value.isNumber()) {
+            throw new SnapshotFormatException(key + ": 须为数值");
+        }
+        return value.asDouble();
+    }
+
+    private static void checkRequiredText(String field, String value, String ctx) {
+        if (value == null || value.isBlank()) {
+            throw new SnapshotFormatException(ctx + ": " + field + " 必填且非空（required）");
+        }
+    }
+
+    private static void checkEnum(String field, Integer got, String ctx, int... allowed) {
+        if (got == null) {
+            return;
+        }
+        for (int a : allowed) {
+            if (got == a) {
+                return;
+            }
+        }
+        throw new SnapshotFormatException(ctx + ": " + field + "=" + got + " 不在契约枚举内 "
+                + java.util.Arrays.toString(allowed));
+    }
+
+    private static void checkFlag(String field, Integer got, String ctx) {
+        checkEnum(field, got, ctx, 0, 1);
+    }
+
+    private static void checkMaxLength(String field, String value, int max, String ctx) {
+        if (value != null && value.length() > max) {
+            throw new SnapshotFormatException(ctx + ": " + field + " 长度 " + value.length()
+                    + " 超过 maxLength=" + max);
+        }
+    }

+            view.put("appliedAt", snap.applied.appliedAt().toString());
+            view.put("nodeCount", snap.applied.graph().nodeCount());
+            view.put("edgeCount", snap.applied.graph().edgeCount());
+        }

+        return graph.getEdges().stream()
+                .filter(e -> e.from().equals(from) && e.to().equals(to))
+                .findFirst()
+                .orElseThrow(() -> new AssertionError("缺边: " + from + " -> " + to));
+    }

+        boolean present = graph.getEdges().stream()
+                .anyMatch(e -> e.from().equals(from) && e.to().equals(to));
+        assertFalse(present, "不应存在的边: " + from + " -> " + to);
+    }
