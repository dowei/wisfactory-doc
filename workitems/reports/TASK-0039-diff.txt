+--   依据：REQ-0018（配置变更留版本与操作人）、ADR-0005（方案 A 补时间线表）、

+-- 重要声明（brief 契约）：
+--   1) 本脚本由 Agent **只产出、不在用户库执行**（用户 MySQL phpStudy 8.0.12@3307）。

+--   3) 时间线表按日志/历史表惯例**不套审计四件套**（无 create_by/update_by/update_time/
+--      deleted/version）——业务写点 Web 会话有操作人但时间线本身只读、按期归档；
+--      与 sys_operate_log 分工：操作日志记「谁调了接口」，时间线记「业务值前后变化」，不双写。
+--   4) full_key 冗余存储（= instance_code + "." + data_code）：数据项逻辑删后仍可按
+--      full_key 查到历史时间线（REQ-0018 验收 3）。
+--   5) 幂等：CREATE TABLE IF NOT EXISTS，可重复执行无副作用。
