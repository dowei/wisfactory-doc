编号：BUG-0008
名称：实例数据项按钮无法打开抽屉（showDrawer 未 defineExpose）
所属模块：前端（Vue 3）
相关功能：FEAT-0018
测试用例：不适用：组件 ref 调用缺陷（单测测内部函数，未测父组件 ref 调用）
状态：已完成
关联任务：TASK-0091
优先级：P1
问题现象：实例管理页每行「数据项」按钮点击无反应，抽屉打不开。浏览器控制台：`Uncaught TypeError: instanceItemDrawerRef.value.showDrawer is not a function`。DOM 中无 .ant-drawer 容器。
预期行为：点击「数据项」打开实例数据项抽屉（TASK-0056 交付的清单/参数覆盖/重生成功能）。
实际行为：`frontend/src/views/iot/instance/components/instance-item-drawer.vue` 定义了 `showDrawer` 但**未 `defineExpose`**，父组件通过 ref 拿到的实例没有该方法，调用 `.showDrawer()` 报 TypeError。对比同目录 instance-form-modal.vue:265 / instance-detail-modal.vue:62 / instance-params-modal.vue:162 均有 defineExpose。
复现步骤：1. 登录后台（admin/admin123）；2. 智慧工厂→实例管理；3. 任一行点「数据项」→ 无反应，控制台报 showDrawer is not a function。
严重程度：严重（阻断实例数据项管理入口）
根因分析：TASK-0056 交付 instance-item-drawer.vue 时，script setup 组件默认对父组件关闭内部方法，必须 `defineExpose({ showDrawer, onClose })` 才能通过 ref 调用；该文件遗漏。单测直接测组件内部 showDrawer 逻辑，未模拟父组件 ref 调用，故没暴露。
修复方案：在 instance-item-drawer.vue 的 `<script setup>` 末尾加 `defineExpose({ showDrawer, onClose })`；加一条父组件 ref 调用测试（断言 mount 后 wrapper.vm.showDrawer 为 function 且调用后抽屉打开），旧版必红/修后绿。微改 TASK-0091 承载。
