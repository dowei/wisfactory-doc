名称：TDengine st_metric_value 建表与指标查询 period 保留字裸列名被拒
所属模块：管理系统（Java）
相关功能：FEAT-0001
测试用例：TC-0025
关联任务：TASK-0077
优先级：P2
问题现象：TDengine 3.4.3.9.community 真机上，st_metric_value 超级表契约 DDL（HttpTdengineAdmin.STABLE_DDL[3]）与 OpenApi 指标查询（OpenApiTimeseriesClient L187）对裸 period 列名稳定返回 code 9728 syntax error；两次复现。TD-0053 第二轮真机复测发现（reports/TD-0053-verify-report2.md），现场以唯一最小偏离形态（period 加反引号）已手工补建 st_metric_value 在位。
预期行为：契约 DDL 与指标查询 SQL 在 3.4.3.9 直接可执行——period 列名以反引号包裹后 code 0，四张超级表契约 DDL 真机全绿。
实际行为：裸 period 被服务器解析为保留字拒绝（9728），st_metric_value 建表失败；代码内两处裸列名形态与现场版本不兼容。
复现步骤：1. TDengine 192.168.31.145:6041（3.4.3.9.community，root/taosdata）；2. 对任一库 REST 执行 STABLE_DDL[3] 原句（period 裸列）→ code 9728「syntax error near period」；3. 同 DDL 将 period 换成反引号包裹 → code 0；4. 执行 OpenApiTimeseriesClient L187 查询原句（裸 period）→ 9728。
严重程度：一般
根因分析：TDengine 3.4.3.9 将 period 列入保留字；上游附录 DDL 与 TASK-0003 交付的契约 DDL 沿用裸列名。TASK-0003 交付期真机不可用（mock 口径，人类裁决），TD-0053 真机联调才暴露——环境版本契约差异未在 mock 层覆盖。
修复方案：HttpTdengineAdmin.STABLE_DDL[3] 与 OpenApiTimeseriesClient 指标查询的 period 列名统一加反引号；补契约测试断言 DDL 含反引号形态（防回归）；修复走微改批（可与 readTimeoutMs 调整合并，待协调者派发）。
